# ROSTOK 🌱

Прототип маркетплейса растений от частных коллекционеров — аналог Avito/Playerok, но для комнатных растений, суккулентов, кактусов, экзотики, черенков и семян.

**[Открыть демо →](https://hurrica95.github.io/RostokMarketPlace/)**

## Что это

Демонстрационная версия сайта, чтобы протестировать идею и показать, как площадка может выглядеть и работать, прежде чем вкладываться в реальную разработку с бэкендом и платежами.

## Возможности

- Каталог с категориями, фильтрами (цена, способ передачи, состояние, проверенные продавцы) и сортировкой
- Карточка товара: описание, условия доставки, отзывы, профиль продавца
- Избранное и корзина
- Форма размещения объявления — новая карточка сразу появляется в каталоге
- Имитация чата с продавцом
- Страница «Как это работает» с описанием механики сделки (защита денег до подтверждения получения) и FAQ

## Технологии

Один самодостаточный HTML-файл: HTML, CSS и JavaScript без сборки и зависимостей. Шрифты подключены с Google Fonts.

## Важно: это демо

- Нет настоящего бэкенда и базы данных — все данные (избранное, корзина, ваши объявления) хранятся локально в браузере, у каждого посетителя свои
- Нет реальных платежей — кнопка «Оформить заказ» ничего не списывает
- Фотографии растений заменены иллюстрациями — загрузка настоящих фото не подключена

## Как запустить локально

Скачайте `index.html` и откройте его в браузере — либо просто зайдите на ссылку из GitHub Pages выше.
